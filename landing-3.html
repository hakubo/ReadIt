How it works

Select. Click. Listen.

No setup wizards, no configuration required. It works the moment you install it.

1

Select text

Highlight any text on any webpage. A "Read" button pops up right next to your selection.

2

Click Read

A floating player appears and starts reading. Audio streams while the rest generates ahead in the background.

3

Make it yours

Pick from 54 voices, set your speed, enable highlighting, save per-site preferences. As simple or as custom as you want.

Private by default, not by promise

The Kokoro TTS model runs entirely inside your browser using ONNX and WebAssembly. There are no API calls to make, no servers to send text to. Your words never leave your machine.

  • ✓ Voice generation happens 100% on-device
  • ✓ Zero network requests for TTS
  • ✓ No analytics, telemetry, or tracking
  • ✓ Works completely offline after setup
  • ✓ Open source — verify it yourself
Features

Simple by default, powerful when you need it

It works out of the box. But if you like to tinker, there's depth here.

🎤 54 natural AI voices

Powered by Kokoro TTS, an 82M-parameter neural voice model. Multiple languages, natural intonation, zero robotic monotone.

⚡ Adjustable speed

Slide from 0.6x to 2x. Speed is applied during playback so generation stays fast regardless of your preference.

🖌 Sentence highlighting

Follow along as the text is read. Choose from six highlight colors. Highlights scroll with the page automatically.

🌐 Per-site settings

Different voice for news vs. documentation? Different speed for long articles? Preferences are saved per domain.

🔌 Works offline

After the initial model download (~326 MB), everything is cached locally. No internet needed for text-to-speech.

🛠 Open source

Fully available on GitHub. Read the code, file issues, send pull requests. Built in TypeScript with React and Vite.

About

The story behind unmute.page

J
Jakub
Developer
Buy me a coffee GitHub

I was tired of subscription-based TTS tools. Every service wanted $10/month, required creating an account, and sent my text through their servers. I just wanted to listen to articles while cooking or walking. That shouldn't require a credit card.

So I built unmute.page. It uses the Kokoro TTS model, which runs entirely in your browser — no cloud processing, no API keys, no data leaving your device. It does one thing well: turns text into speech.

But I also built it for people like me who want to tweak things. You can pick different voices for different websites, adjust speed, enable sentence highlighting, define content areas with CSS selectors. It just works out of the box, but it rewards you for digging deeper.

This extension is free, open source, and will stay that way. If you find it useful and want to support development, I'd appreciate a coffee.
